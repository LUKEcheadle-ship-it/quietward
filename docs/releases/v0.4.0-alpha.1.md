# QuietWard v0.4.0-alpha.1

## Experimental cross-platform alpha

This release adds a real-host-qualified Windows 11 experience to the corrected Debian 12 alpha. QuietWard remains observation-only: it detects, records, prioritizes and explains; it does not automatically remediate the host.

The original qualification campaign was completed under the project’s pre-rename working title. The final QuietWard source must rerun the rename-sensitive packaging and installer checks before publication.

## Supported platforms

- Windows 11
- Debian 12

Windows 10 and other Linux distributions have not completed independent qualification.

## Highlights

- User-scoped offline Windows installer and limited startup task.
- Read-only local dashboard with plain-language findings and evidence status.
- Windows process, listener, persistence, file-integrity, self-integrity and optional outbound-connection monitoring.
- Read-only Microsoft Defender status evidence.
- Installation-specific privacy identities and signed local evidence.
- Safe upgrade and conservative uninstall/reinstall paths.
- Portable platform selection and broader experimental systemd Linux compatibility.
- Review-only remediation plans that cannot execute in this release.

## Windows installation

## Known limitations

- This is an experimental alpha, not stable endpoint protection.
- Windows Security-log collection is permission-dependent and disabled by default.
- Docker Desktop support was not exercised on the original Windows qualification host.
- Outbound connection monitoring is opt-in.
- Automatic remediation is unavailable.
- The dashboard is local and read-only.
- Historical qualification databases must not be distributed.

## Security and privacy

- No cloud telemetry.
- No public listener.
- No arbitrary command or shell execution by the product.
- No automatic quarantine, deletion, process termination, firewall changes or host isolation.
- Identity-bearing values are pseudonymized with an installation-specific key.
- Evidence is retained locally and can be HMAC-signed.
