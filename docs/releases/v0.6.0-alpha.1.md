# QuietWard 0.6.0-alpha.1 preview

Python package: `0.6.0a1`. This file describes current development source. The latest published GitHub prerelease remains 0.5.0-alpha.1 until a new release is explicitly published.

This preview adds the sanitized, verified local handoff to QuietWard Response 1.1. QuietWard remains observation-only: `actions_executed == 0` and `executable_proposals == 0`.

The September review fixes version-aware release verification and clock-dependent test fixtures. The training CLI now requires separate held-out evaluation data, and the synthetic detection gallery makes rule behavior inspectable. These are software and synthetic checks, not an independent real-world detection benchmark.

Run `python scripts/validate_migrated_release.py --pretty` for the current source gate and `python scripts/verify_v06_response_handoff.py` for the handoff checks. Native Windows and Debian release qualification on the final commit remains necessary before publishing a new platform-qualified release.

The eventual publication artifact is `quietward-v0.6.0-alpha.1-source.zip`, accompanied by a SHA-256 checksum sidecar. Verify the archive independently before installation. No new archive is advertised as published by these notes.

Native Windows 11 and Debian 12 qualification must run on the exact public release SHA before publication.
