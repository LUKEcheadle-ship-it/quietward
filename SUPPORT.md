# Support

QuietWard is an experimental observation-only security monitor. It is provided without warranty and does not replace antivirus, system administration, security monitoring, or incident-response professionals.

Use GitHub issues for installation questions, reproducible bugs, and feature proposals after the repository becomes public. Remove hostnames, IP addresses, usernames, file contents, tokens, logs, and scanner data before sharing diagnostics.

Use the private process in `SECURITY.md` for vulnerabilities or bypasses. Qualified experimental-alpha targets are Windows 11 and Debian 12 with Python 3.11 or newer; Debian service installation requires a systemd user session.
